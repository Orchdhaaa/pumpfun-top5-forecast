A deterministic forecaster for the top 5 new pump.fun coins by market cap, 24 hours out. It reads the house's 10-minute snapshots of newly launched Solana coins and writes a single probabilistic forecast — place probabilities, a top 5, and market-cap size bins — for the seven hourly answer reads.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
